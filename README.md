# Samarkand — презентация

Файлы: `index.html` (сайт), `admin.html` (админка), `base.css`, `store.js`.

## Запуск
Открывайте через GitHub Pages или локальный сервер (`python3 -m http.server`), не двойным кликом по файлу.

## GitHub
1. Создайте репозиторий и загрузите все 4 файла в корень.
2. Settings → Pages → Branch: `main` / root → Save.
3. Сайт: `https://<логин>.github.io/<репозиторий>/`, админка: `.../admin.html`.

## Важно
Фото и видео хранятся в браузере, где вы работали в админке. Показывайте презентацию с того же устройства и браузера.
Для другого устройства: админка → «Копия и данные» → скачать копию → загрузить на новом устройстве → «Сохранить».
